# Installation

## Phone or tablet

1. Open the [latest release](https://github.com/Anders0lesen/free-iperf3-client/releases/latest).
2. Download the `.apk` file.
3. Open it and allow installation from that browser or file manager when Android asks.
4. Start **Free iperf3 Client** from the app list.

## Android TV or Google TV

1. Download the same APK on a computer or phone.
2. Transfer it to the TV with your preferred sideloading method.
3. Install it and start **Free iperf3 Client** from the TV app list.

The app supports Android 9 (API 28) and newer. It has no account, analytics, ads, tracking, storage access, or background service.

## Upgrading

Install the newer APK over the existing app. The original v0.1 development build may have a different generated signature; if Android reports a signing conflict during the v0.2 upgrade, uninstall v0.1 once and install v0.2 fresh.
