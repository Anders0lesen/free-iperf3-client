# Installation

## Phone or tablet

1. Open the [latest release](https://github.com/Anders0lesen/free-iperf3-client/releases/latest).
2. Download the `.apk` file.
3. Open it and allow installation from that browser or file manager when Android asks.
4. Start **Free iperf3 Client** from the app list.

Direct v0.3.6 asset: [free-iperf3-client-v0.3.6.apk](https://github.com/Anders0lesen/free-iperf3-client/releases/download/v0.3.6/free-iperf3-client-v0.3.6.apk)

## Android TV or Google TV

1. Download the same APK on a computer or phone.
2. Transfer it to the TV with your preferred sideloading method.
3. Install it and start **Free iperf3 Client** from the TV app list.

The app supports Android 9 (API 28) and newer. It has no account, analytics, ads, tracking, file access, or background service.

## Upgrading

Early releases use development signing. If Android says the new APK conflicts with the installed package, uninstall the old **Free iperf3 Client** first and then install the new APK. This clears the recent-server list; results are never stored.
